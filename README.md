My AI agent built a full GTA 6 open-world game — **NEON BAY** — from one prompt:
Vice City streets, 5-star wanted chases, police roadblocks, a helicopter
spotlight, traffic and pedestrians, 8 story jobs, 7 weapons. 3,570 lines of
code, three.js, playable in a browser.

The video shows the prompt, the agent working, and the finished game running,
and ends on make.fun's referral end card. It was posted on X as a native
video; `POST.json` names the post, and the house reads its views and
interactions from X.

NEON BAY itself was built for the make.fun gta6-01 bounty
("Make GTA 6"): the fixed build (entry `01a20703`) passed every intake check
and the dev gate with a dev rate of 0.988731 (12 won, 0 drawn, 0 lost), and is
the picked final entry there.

## How to play NEON BAY

Serve `game/` with any static file server and open `index.html`. The game is
in the [bloomsX/neon-bay](https://github.com/bloomsX/neon-bay) repository.
